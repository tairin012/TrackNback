# TRACKNBACK

A lost and found web app built with PHP and MySQL.

## Setup
1. Install XAMPP and start Apache and MySQL.
2. Copy this folder to `htdocs/TRACKNBACK`.
3. In phpMyAdmin, create a database named `tracknback` and import `SQL/tracknback.sql`.
4. Open http://localhost/TRACKNBACK/abc.php

## Features
- User registration and login
- Post lost and found items
- Admin approval of posts
- Notifications and community page
